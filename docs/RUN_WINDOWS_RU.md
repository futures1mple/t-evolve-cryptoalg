# Замеры на Windows: пошагово

## 1. Установить компилятор (один раз, около 10 минут)

1. Скачать и установить MSYS2: https://www.msys2.org (путь по умолчанию `C:\msys64`).
2. Открыть из меню «Пуск» **MSYS2 UCRT64** и выполнить:

       pacman -Syu
       pacman -S mingw-w64-ucrt-x86_64-gcc

   (если после первой команды окно закроется, откройте его снова и повторите вторую).
3. Добавить `C:\msys64\ucrt64\bin` в переменную среды `PATH`: «Пуск» → «Изменение системных
   переменных среды» → «Переменные среды» → `Path` → «Создать».
4. Проверить в обычной командной строке (`cmd`): `gcc --version` печатает версию.

## 1а. Скачать код

Проще всего через GitHub Desktop: File → Clone repository → `futures1mple/t-evolve-cryptoalg`.
Другой вариант — на странице https://github.com/futures1mple/t-evolve-cryptoalg нажать
Code → Download ZIP и распаковать (тогда в результатах будет `commit: unknown` — это не страшно).

## 2. Подготовить компьютер

* Подключить питание, включить режим «Максимальная производительность» (Параметры → Система →
  Питание).
* Закрыть браузер и другие программы; не пользоваться компьютером во время прогона.

## 3. Запустить

В `cmd`, из папки репозитория `t-evolve-cryptoalg`:

    scripts\build_windows.bat
    scripts\run_windows.bat

Прогон занимает около часа. Самый долгий шаг — последний (агрегация 10 000 бюллетеней).

## 4. Прислать результаты

Появится папка `results\windows\<дата_время>`. В ней:

* `machine.txt` — процессор, память, режим питания, версия компилятора;
* `test_core.txt`, `test_protocol.txt` — тесты (в конце должно быть `passed (0 failures)`);
* `ballot_rej_*.csv`, `ballot_rej_summary.csv` — эксперимент с отбраковкой;
* `bench.csv` — все замеры.

Скопируйте эту папку в `Main Paper` — дальше я подставлю числа в статью.

Если что-то упало с ошибкой — пришлите текст из окна `cmd`.
